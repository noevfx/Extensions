Caminho 02 / Links do cliente ou do roteiro

Cole. Selecione. Continue editando.

  1. Abra o painel. Procure Janela → Extensões → Noe VFX Downloader for Editors. Confira o nome do projeto reconhecido.
  2. Cole os links. Uma lista inteira do documento ou um endereço após o outro. A colagem separa os itens automaticamente.
  3. Playlist? Cole o endereço dela e espere os títulos. Marque tudo ou apenas os itens que quer usar.
  4. Escolha o arquivo. Vídeo: Nativa, 1080p ou 720p. Só áudio: MP3, M4A ou WAV.
  5. Confira e importe. O botão informa quantidade e formato. Clique em “Baixar e importar…” e acompanhe o resultado de cada item.

Compacto ou completo? O painel começa compacto: links, qualidade e baixar. Conferir seleção expande os itens; playlists abrem essa lista automaticamente. Alterne pelo botão Modo completo / Modo compacto, sem perder links, seleção ou formato. A preferência fica salva em cada programa.

No painel, o destino é sempre o projeto reconhecido. Para uma pasta avulsa ou para FLAC/Opus, use a janela do navegador.

O app fixa o projeto de destino ao enviar a lista. Mudar de projeto durante o download não redireciona os arquivos seguintes.

Dois jeitos de começar. A mesma seleção.

Já está pesquisando? Envie um vídeo pelo menu do player ou abra a playlist no navegador e escolha o destino Adobe.

Já está editando? Cole os links no painel. O roteiro pode trazer um, dois ou vários endereços: o painel organiza a seleção antes de baixar.

Se algo sair do caminho.

Baixou, mas não apareceu no projeto.

Confira a mensagem de cada item. O projeto de destino deve continuar aberto e o componente Adobe precisa estar ativo. Se houver erro de importação, o arquivo baixado fica na pasta do trabalho e o painel mostra o motivo informado pelo editor.

A playlist pede login.

O painel Adobe não lê a sessão do navegador. Tente pelo popup da extensão com a conta conectada, se o acesso for permitido. Conteúdo privado, removido, bloqueado ou protegido pode não estar disponível.

O painel não aparece.

Confira se instalou a edição for Editors e se seu editor oferece suporte ao CEP. Feche o editor, rode o instalador dessa edição e abra novamente. Observe as etapas da instalação Adobe.

Tenho Premiere e After Effects abertos.

O painel de cada programa envia para seu próprio projeto. No navegador, escolha explicitamente Premiere ou After Effects. Se o projeto não for identificado, o app avisa antes de iniciar.

Preciso converter todos os vídeos?

Não. O app prefere H.264 na resolução escolhida quando a plataforma oferece esse formato. Só prepara o que for necessário para compatibilidade. A escolha CPU/GPU continua automática e é informada no progresso.
