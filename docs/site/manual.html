Caminho 02 / links recebidos ou reunidos

O cliente mandou. O roteiro já tem os links.

Copie um ou vários endereços e continue dentro do editor.

Abra o painel.

No Premiere Pro, procure Janela → Extensões → Noe VFX for Editors. Confira se o painel mostra o nome do seu projeto e a pasta de destino.

Cole o link do vídeo.

Copie o endereço da página do vídeo e cole no campo de links. Para baixar vários, coloque um endereço por linha.

Escolha a qualidade.

Nativa busca a maior resolução disponível. 1080p e 720p limitam a resolução. Quando houver H.264 na qualidade escolhida, o app prefere esse formato e evita reconverter o vídeo.

Clique em “Baixar e importar”.

Acompanhe cada item no painel. Se precisar converter, o progresso informa a etapa e o processador ou a GPU usada. Ao terminar, o vídeo aparece no bin _Noe VFX Downloader do projeto.

Para baixar vários vídeos

Escolha pelo que você tem em mãos.

Vídeos na mesma página: no menu integrado ao vídeo, use “Baixar todos os vídeos desta página”. Os vídeos detectados são enfileirados para a pasta de downloads.

Uma lista de endereços: use “Vários links” no popup. Cole um link por linha; no menu de destino, escolha a pasta ou o projeto do editor. No painel Adobe, cole a mesma lista no campo de links e use “Baixar e importar”.

Escolha a qualidade no menu antes de iniciar e confira o andamento de cada item. O envio para o projeto exige a edição for Editors e o componente Adobe instalado.

Pronto para editar

Na pasta e no projeto.

O arquivo fica no disco, dentro da pasta do trabalho. O painel também cria o bin para organizar os vídeos importados.

Se algo sair do caminho.

O painel não aparece no menu. O que faço?

Feche e abra o programa após instalar. Confira se usou a edição for Editors. Se o painel continuar ausente, rode novamente o instalador dessa edição e observe os avisos da etapa Adobe.

O painel pede para salvar o projeto.

Salve o projeto numa pasta do trabalho e espere o painel reconhecer o nome e o destino. O app precisa desse caminho para saber onde guardar os arquivos.

Baixou, mas o arquivo não apareceu no projeto.

Mantenha o projeto correto aberto e confira a mensagem de cada item no painel. O download e a importação são etapas diferentes; se a importação falhar, veja a pasta _Noe VFX Downloader do trabalho para localizar o arquivo e conferir o aviso.

Um MP4 precisa ser convertido?

MP4 é o recipiente do arquivo. Se o vídeo já estiver em H.264 compatível, ele é preservado. Se apenas o áudio precisar virar AAC, só o áudio é convertido. AV1 e VP9 podem exigir conversão para o fluxo de compatibilidade do Downloader.
