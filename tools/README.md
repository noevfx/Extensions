# Ferramentas do projeto

| Arquivo | Função |
|---|---|
| build.py | Gera os dois produtos em dist; guarda compilações por versão em build e arquiva pacotes anteriores. |
| manual_demos.py | Sincroniza as demonstrações do site com as interfaces do app. |
| release_notes.py | Gera notas da release e hashes; não publica. |
| verify_update.py | Ensaia atualização/migração em pastas isoladas. |
| capturar-telas.js | Ferramenta auxiliar de captura das telas de configuração e do navegador. |
| release.py | Prepara commit, tag e envio para publicação pelo workflow. Só executar após autorização explícita do responsável. |

Os produtos públicos são Noe VFX Downloader e Noe VFX Downloader for Editors. Pastas e IDs internos usados pelas instalações existentes são mantidos para preservar a compatibilidade.
